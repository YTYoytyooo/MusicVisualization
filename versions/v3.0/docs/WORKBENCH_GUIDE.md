# V3 制作工作台使用指南

本指南对应 [Start V3.cmd](<D:/2_datas/Vm/Start V3.cmd>) 启动的 [8768 工作台](http://127.0.0.1:8768)。它使用现有固定模型制作可编辑作品；没有新增训练，也不代表模型准确率已经超过 V2。真实整曲制作已通过限定范围验收，浏览器操作与尚未现场验证的交互分别记录在[本轮验收记录](D:/2_datas/Vm/versions/v3.0/docs/WORKBENCH_ACCEPTANCE.md)。

## 1. 建立可编辑作品

### 复用已有 V3 分析

左侧展开“复用分析 / 导入 V2 作品”，选择已完成分析、作品名称和初始驱动模型，点击“复用分析建立作品”。

原分析保留在 [data/v3.0/projects](D:/2_datas/Vm/data/v3.0/projects)。新作品建立在 [data/v3.0/works](D:/2_datas/Vm/data/v3.0/works)，包含自己的音频副本、原生 V/A 数据、修订和输出。原分析及其凭证不因人工编辑而改变。

建立作品时会校验音频、分析凭证和固定模型身份，并从实际音频提取用于画面节奏的节拍信息。节拍缓存与情绪预测分开；它不是新增情绪标签。

### 导入已有 V2 项目

选择已有项目，或填写 V2 项目的完整目录路径，点击“导入为 V3 副本”。

- V2 原件保持原样，初始驱动模型仍为 V2。
- 原始五维预测、历史修订、计划与输出保存在新作品的 `archive/v2-original`。
- `migration.json` 记录原文件校验值和修订编号映射。
- 旧版能量、紧张度、明亮度只作为历史参考，不替代新 V3 的 V/A 或声学测量。
- 原来的合成演示保留合成标记；真实歌曲不会因此被标为合成。
- 未知编辑字段、缺失父修订或校验不一致会阻止发布导入结果，并保留暂存信息供排查。

历史视频留在归档内，不会改名冒充本次新生成的 V3 输出。可以在导入作品中按原模型和修订重新生成参考视频。

### 使用已经存放在 Vm 内的音频

在“新建分析项目”填写完整路径，或从“已有素材”选择。选择 GPU 或 CPU；需要原 V2 曲线时勾选“同时计算 V2 对照”。输入的随机种子控制视觉制作，不改变冻结模型的三个训练种子。

同内容音频优先复用经过校验的既有结果。同名但内容不同的文件不会复用旧预测。固定推理的最终测试隔离及暂停标注集合限制仍有效。模型使用整曲上下文，0.5 秒输出间隔不是实时识别延迟。

## 2. 驱动模型、对照曲线和数值层

“作品驱动模型”决定当前制作基线及正式视频的情绪输入。“显示原始对照曲线”只控制图上可见的比较线，不更换画面驱动。

切换驱动模型时，可以选择保留人工修改并重新校验，或使用新模型原始基线。区间偏移依赖基线，因此更换模型后可能越界；校验失败时应先调整偏移，不能绕过检查。成功切换保存为新修订。

| 数值 | 含义 | 是否影响作品 |
|---|---|---|
| 原始预测 | 固定模型的原生输出 | 是制作起点，始终只读 |
| 校准结果 | 目前没有通过验证的可用校准 | 不生成替代数值 |
| 显示平滑参考 | 仅让查看时的参考线更易读 | 不改变修订或视频 |
| 制作平滑基线 | 明确应用到作品的可选处理，默认关闭 | 会影响作品，随修订保存 |
| 生效修订 | 制作基线加人工 V/A 修改 | 用于视觉与运动规划 |

制作顺序是：原始预测 → 可选制作基线平滑 → 人工情绪修改 → 生效 V/A → 视觉与运动控制 → 视频。人工目标在制作平滑之后应用，避免目标值被再次平滑冲淡。

V3 原生采样间隔为 0.5 秒，V2 为 0.1 秒。两者时钟不统一拉伸，V/A 缺失掩码各自保留。旧 V2 在末尾不足一个完整窗口时，使用明确记录的兼容保持策略直到真实音频结束；这不会增加原始采样点，也不会填补歌曲中间的缺失。

RMS / dBFS 描述声学强度，频谱重心以 Hz 描述频谱分布。它们不等同于心理唤醒或效价。模型紧张度仍未独立验证；三种子分歧也不等于置信概率。

## 3. 编辑情绪曲线

点击波形定位歌曲，使用整曲概览、缩放与平移调整可见范围。A/B 两个时间点可循环播放局部。视图变化不改动音频和数值。

右侧选择情绪字段、操作和时间：

| 操作 | 用法 | 结果 |
|---|---|---|
| 单点目标 | 指定某时刻的 V 或 A 目标及前后过渡 | 在目标时刻准确到达指定值 |
| 区间设值 | 指定开始、结束和目标值 | 区间内维持目标值 |
| 区间偏移 | 指定开始、结束和偏移量 | 保留原变化形状并整体抬升或降低 |

过渡可选线性、smoothstep 平滑、smootherstep 柔和。新操作默认柔和过渡；导入的旧记录保留原设置。区间的进入/退出过渡位于区间两端外侧，整个影响范围必须落在歌曲内。单点目标要求非零的前后过渡。

输入时曲线即时反馈，Enter 或离开输入框时确认该次操作；Esc 取消尚未确认的输入。拖动黄色关键帧可修改时间和值，松开后进行校验。同字段的冲突区间或数值越界会指出问题，不能静默截断。

这些即时反馈是曲线与参数预览。已有视频不会随草稿自动变化；需要生成新的局部预览或正式输出。

## 4. 草稿、撤销与历史修订

- 最多保留 50 步已校验操作。一次连续输入或一次拖动算一步，非法修改不进入历史。
- 使用撤销/重做按钮，或在输入框之外使用 Ctrl/Cmd+Z、Ctrl/Cmd+Shift+Z、Ctrl+Y。输入框内仍使用文字自身的撤销。
- 撤销后新增操作，旧重做分支不再可用。切换项目、切换修订和保存后，草稿操作历史重新建立。
- 已校验草稿保存到当前浏览器本地，按作品、修订和驱动模型区分。清除浏览器数据可能丢失这些草稿；正式修订保存在磁盘。
- 切换项目或修订前，可以保存新修订、保留本地草稿后继续，或取消切换。重新打开时恢复草稿需要再次通过服务器校验。
- “保存为新修订”创建新编号，不覆盖原始结果或旧修订。选择历史修订后，按钮会变为“以此草稿恢复为新版本”。
- 两个页面同时操作时，服务器检查保存所依据的版本；发现版本已变化就拒绝覆盖，应重新加载再处理草稿。

原始预测、当前草稿、所选历史修订和当前视频属于不同对象。查看画面时应同时看修订编号、驱动模型和是否存在未生成的修改。

## 5. 视觉参数与九种运动模式

视觉页使用真实自动规划基线，可修改主色相、色相范围、饱和度、画面亮度、粒子数量、速度、扰动和拖尾。基线未准备完成时，等待“视觉规划”任务，不会用模拟值代替真实计划。

视觉参数也支持单点、区间设值、偏移及过渡。色相跨越 360° 时沿较短圆弧过渡。粒子数量和拖尾在渲染控制中按其整数规则处理。

运动层保留旧引擎，并可选择多模式引擎：上升、下沉、环流、螺旋、扩散、汇聚、流星、波浪、湍流。上轨显示自动模式，下轨显示人工覆盖后的结果。

手动运动覆盖需要指定区间、模式、控制参数和进出过渡。混合时显示多个模式及其权重。速度、方向、中心和半径等是画面控制；自动运动规则是艺术映射，不是情绪分类结论。

单独修改视觉覆盖或运动设置不应重新运行情绪模型；改动生效 V/A 后，会重新计算依赖它的计划。粒子历史可能影响修改区间之后的画面，因此片段恢复与缓存需要验证完整配置。

## 6. 局部预览与参考视频

点击“生成局部预览快照”，会固定提交时的草稿、模型和配置，不创建正式修订。随后继续编辑也不会改变正在生成的快照。

- 已选中情绪、视觉或运动修改时，默认覆盖其完整影响范围，并前后各扩展 2 秒；边界限制在歌曲内。
- 未选择修改时，默认预览前 10 秒。
- 快照默认 640×360 / 30fps，属于草稿预览，不能把不同规格的像素结果当成正式视频的严格逐帧对照。
- 片段生成从兼容检查点恢复，或从曲首推进状态，不在片段起点凭空重置粒子。

在“原版 / 参考视频”选择已生成结果，可按歌曲绝对时间同步播放，并选择声音来自哪一侧。浏览器同步用于观看比较；严格逐帧等价需要单独的同配置验证，不能只靠播放器肉眼判断。

## 7. 输出整曲视频与数值

先保存正式修订，再点击“生成当前已保存版本”。开始时间设为 0、结束留空，即输出到歌曲结尾。

| 设置 | 用途 |
|---|---|
| 1280×720 / 30fps | 默认正式规格 |
| 640×360 | 快速草稿，画面不作为正式规格的像素等价证据 |
| 1920×1080 | 较高分辨率，耗时和磁盘占用更大 |
| 分析版 | 显示轨迹、数值与修订标记 |
| 展示版 | 纯可视化画面 |

帧率还可选择 24 或 60fps。片段范围按输出帧边界处理，实际范围记录在输出信息中。不同尺寸或帧率不能共用不兼容的渲染状态。

“全部输出历史”显示每次生成的修订、模型、范围、规格、时间和状态。选中一个输出后，可以下载：

- 原始模型 CSV：保留对应模型的原生时间轴及有效性信息。
- 生效情绪 CSV：本次制作采用的 V/A；这是制作数据，不是新增训练标签。
- 视觉计划 CSV，以及多模式输出的运动计划 CSV / JSON。
- 逐帧数值 CSV：实际写入视频的帧及其控制值。
- 输出记录及有声音的视频。

原始采样表与逐帧表的行数不同属于正常情况。逐帧值由明确的制作规则得到，不得当作模型新增预测点。开启制作基线平滑时，对应基线文件也保存在该输出目录。

## 8. 任务状态、取消和重试

底部任务区可切换“当前项目 / 所有项目”，查看等待、运行、完成、失败及取消状态。耗时任务按队列运行，避免重复占用重型资源。关闭浏览器不等于取消已启动的工作，应使用任务上的取消按钮。

重试会检查原进程是否仍活动，以及原任务的配置、音频、模型、代码和相关凭证。通过后使用原配置创建关联的新任务编号；不会为了重试删除配置、放宽校验或覆盖已完成结果。如果文件已经改变，应先查明变化原因，再明确建立新任务。

编码失败时，中间画面、数值文件和编码日志会保留，状态不会标成成功。打开项目失败、显示校验错误或恢复被拒绝时，保留原文件，不手动改写哈希来绕过检查。
