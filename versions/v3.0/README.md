# V3 音乐可视化制作工作台

V3 默认入口现在指向完整制作工作台：复用已有分析或导入 V2 作品副本，编辑情绪、视觉和运动轨道，保存独立修订，再生成整曲视频。原来的研究预览仍保留为独立入口。

**工作台补全与模型精度是两件事。** 本次使用已有音频、固定模型和独立 Python 环境，不增加训练数据、不训练新模型，不打开 622 首最终测试集。B01/B00 的研究身份、尚未通过的逐库逐维门槛，以及校准和紧张度不可用的结论均保留；不能据此宣称模型已经超过 V2。

## 启动与第一步

1. 双击 [Start V3.cmd](<D:/2_datas/Vm/Start V3.cmd>)，保留服务窗口。
2. 打开 [本机 V3 工作台](http://127.0.0.1:8768)。
3. 左侧展开“复用分析 / 导入 V2 作品”。已有 V3 分析可直接建立可编辑作品；已有 V2 项目使用“导入为 V3 副本”。
4. 也可填写已经保存在 Vm 内的音频路径，建立分析项目。相同音频优先复用经校验的已有结果；分析完成后再手动制作视频。

启动器使用已有独立 Python：D:\2_datas\Vm\data\training\next_va\env\Scripts\python.exe。不会自动安装环境、下载模型或训练。GPU 不可用时，分析应明确选择 CPU。

## 工作台内容

- **作品与模型：**原始分析和可编辑作品分开保存；驱动画面的模型与只用于查看的对照曲线分别选择。
- **情绪编辑：**V/A 单点目标、区间设值、区间偏移、三种过渡、关键帧拖动、50 步撤销/重做、本地草稿和历史修订恢复。
- **视觉与运动：**真实 MCTS 视觉规划及参数覆盖；保留旧运动引擎，并提供九种模式、自动轨道、人工覆盖和混合过渡。
- **预览与制作：**冻结草稿快照、局部预览、已有视频同步比较；整曲或片段输出，默认 1280×720 / 30fps，提供 360p 和 1080p 尺寸。
- **结果追溯：**输出历史、真实任务状态、取消和经校验的重试；原始、生效、视觉及运动 CSV 与逐帧实际控制记录。

原始 V3 预测保留 0.5 秒时钟，旧 V2 保留 0.1 秒时钟。缺失维度各自保留空白。显示平滑不影响作品；“制作基线平滑”才进入制作计算，人工修改在其后生效。声学 RMS / dBFS、频谱重心及节拍与心理情绪分开解释。
