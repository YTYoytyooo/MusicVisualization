# 优化版工作台：任务、预览与长曲

本轮在独立Studio目录升级，不覆盖旧项目、模型、依赖或原视频。入口仍为 `Start Studio.cmd` / 本机8765端口。

## 推荐体验流程

1. 导入音频并分析。阶段进度显示已处理音频片段/情绪采样；取消后显示正在取消，等待当前批次或底层调用结束。
2. 生成原始修订视频。长曲先做低分辨率短片段，避免一开始等待完整正式视频。
3. 在情绪时间线上放大、平移，或输入可见起止秒数。点击波形跳转播放，选择人工修改后用定位修改查看该段。锁定纵轴便于比较修改幅度。
4. 输入值或拖动关键点，确认这一步；撤销/重做保留50步。不要将视频播放器旧画面误认为当前草稿的实时渲染。
5. 点击局部预览按钮。当前调整先确认并校验，系统另存冻结草稿快照。选中修改时默认覆盖整个影响范围并前后各扩2秒；无选中修改默认前10秒。默认640×360、30FPS，明确标为近似草稿，不更新正式修订指针。
6. 选择已有参考视频，开启对比。两路按歌曲绝对时间同步，声音只来自一侧。浏览器同步允许少量漂移，不是逐帧校验工具。
7. 满意后保存正式修订，再生成1280×720、30FPS的最终视频。原始与历史视频保留。

## 新界面

- 流程导航与修订提示区分草稿、正式修订、冻结预览及播放器当前版本。
- 时间线提供放大、缩小、左右平移、定位范围、定位修改、返回全曲与纵轴锁定；这些动作不修改数值或撤销历史。
- 平滑开启时显示原始、平滑基线、最终修订三条情绪曲线，使用共同刻度。
- 任务列表显示已完成数量/单位、取消状态、日志和终态重试。
- 项目可以按名称搜索；任务默认显示当前项目最近5项及活动任务，可切换所有项目或展开历史，并提示其他项目仍在运行的任务。
- 桌面使用编辑区与参数面板；窄屏重新排列，不通过隐藏溢出来掩盖控件。

## 任务与失败恢复

临时规划按输入会话和单调候选序号合并。新候选释放旧引用；已无使用者的临时任务取消。共享消费者和正式确认拥有独立保护，不能被后来的临时输入取消。旧请求晚到也不会重新绑定或取消新任务。

已完成候选规划在浏览器保留最近8项，不淘汰正在使用的项。磁盘规划与旧输出不会自动删除。关闭页面后已提交的正式生成继续运行；浏览器未确认输入不保证保存。

“重试”复制原任务冻结参数，而不是偷偷使用最新草稿。它不是从任意失败帧续做，也不保证代码升级后像素与旧环境相同。查看日志为最多64KiB文本尾部并过滤常见凭证，不提供任意路径读取。

Windows读取任务状态可能短暂阻止原子替换。JSON发布进行有限次退避重试，始终保留旧完整文件；永久权限问题仍明确失败，不无限等待或截断旧文件。

## 缓存与版本

- 特征缓存：音频内容、实际本地CLAP文件校验、提取/预处理代码及相关依赖。
- 预测缓存：特征键、情绪权重、推理代码/配置及依赖。
- 规划缓存：原始分析、生效情绪编辑、平滑配置、种子、规划代码与配置。
- 渲染记录/检查点：冻结修订、规划、视觉参数、音频、画面尺寸/FPS/模式、渲染代码和运行环境。

不盲目迁移旧缓存，不删除旧结果。只改画面不会使特征/预测缓存失效。第一次升级重新规划是预期行为；旧视频仍可播放。

CLAP使用已存在的完整本地快照并固定路径；缺失时明确报错，不隐式下载或训练。阶段配置与结果校验信息保存在项目、缓存与渲染记录中。

## 检查点与性能

情绪推理仅构建当前批次窗口；HUD历史轨迹增量绘制，最近2秒高亮独立处理，向后跳转时重建。

渲染每10秒保存一个JSON+NPZ检查点，包含粒子、生命周期、随机源、轨迹、向量场、帧号及HUD历史画布。片段生成只复用同一修订、同一配置的较早检查点。第一次仍需要从头推进；修改修订或尺寸/FPS后不会跨配置误用。

检查点验证配置、哈希、数组类型和尺寸，不允许pickle；失败保留损坏文件供诊断，并回退完整重放。检查点增加磁盘占用，当前不会自动清理。

模拟一致性以编码前像素和数值检验。整段与片段分别经过有损编码，解码后的像素或文件字节不要求相同。

生成前检查输出目录可写性、编码器与估算可用磁盘空间。空间估算不是上限保证，运行中磁盘仍可能被其他程序占满。

## 可选渲染平滑

默认关闭，可设置0.1至5秒窗口。开启时仅对原始V/A做对称滑动平均，并在相邻平滑采样间线性插值；Energy/Tension/Brightness不变。随后才应用人工编辑，保证人工单点目标精确命中。

源数组永远只读；渲染导出另外保存 `predictions_baseline.csv`。配置进入撤销历史、本地草稿、正式修订、规划键及渲染记录。

这是非因果的离线表现处理，会利用前后音频采样，可能削弱短时峰值。它不是模型精度提升，也不能保证整数粒子数量、颜色绕环及所有视觉事件都没有跳变。

## 验证入口

```
python -m unittest discover -s tests -v
node scripts/check_math.cjs
node scripts/browser_live_check.cjs
node scripts/browser_upgrade_check.cjs
python scripts/verify_upgrade.py --stress --model-smoke
```

浏览器脚本会创建独立合成测试项目。最后一项包含较长计算：3/10分钟合成压力输出是320×180、10FPS，不冒充默认720p正式长曲验收；真实模型部分用既有模型与6秒歌曲片段。运行证据以 `validation-output/upgrade-acceptance/report.json` 的实际状态为准。
