### 本轮边界

- 自动运动是 V/A 与音频特征的美术映射，不是新训练的分类器；匹配分数不是置信度。稳定预测可长期保持同一种运动，不强制每首歌出现九种效果。
- 轨道即时反馈是控制计划，不是实时重渲染的视频。生成速度受画面尺寸、粒子数量、拖尾和 CPU 影响，建议先做局部预览。
- 当前真实歌曲验收复用此前保存的预测，明确标注来源；不把它称为本轮重新执行模型推理。跨机器文件字节一致、模型准确率、发行安装包不在本轮验证范围内。
