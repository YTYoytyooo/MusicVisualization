# Flow-v1 引擎接口与边界

`VideoRenderer.render_frame(..., motion=None)` 默认保持旧粒子路径。传入合同中的 motion 帧时启用独立 `FlowParticleSystem`；旧粒子状态与随机源不被推进。

## 数值语义

- 对外 `speed` 为画布短边/秒，`radius` 为画布短边比例；内部位置为像素、速度为像素/秒。
- 方向右 0°、下 90°、左 180°、上 270°；`rotation=1` 按屏幕坐标顺时针，`-1` 逆时针。
- 物理时间步为 `1/fps`。目标速度按时间常数跟随，转向上限 2π 弧度/秒，速度幅值加速度上限 1.5 短边/秒²，完整速度向量加速度上限 2.5 短边/秒²。
- 多模式混合采用当前行进方向附近的角度插值，单独混合速度幅值。上升与下沉过渡通过转弯完成，不相加为零向量。
- `speed=0` 为明确静止控制。`pulse` 可在节拍时使基础目标速度最多增加 30%；瞬态仍受加速度约束。
- 九种模式使用粒子位置上的解析场，不创建整幅屏幕的向量场。规则主运动不依赖 turbulence。

## 出生、环流与轨迹

- 普通升降/波浪初始铺满画面，后续从来流边界出生；流星从来流边界开始，短寿命并渐入/渐出。
- 环流在稳定半径的环带出生，每个粒子的半径因子固定；径向恢复用于抑制积分漂移。
- 向外扩散和正 radial 螺旋从中心附近出生；汇聚和负 radial 螺旋从外圈出生。
- spiral 的 radial 正负分别表示外旋/内旋。expand/gather 按 radial 符号控制径向方向；其 radial=0 采用模式本义。静止请使用 speed=0。
- history 最多保存 2 秒。拖尾按真实年龄衰减；每个出生代数不同，绝不连接重生前后位置，也不跨屏幕边界画整屏长线。
- radius 控制的是环流目标环带或螺旋的尺度，并非所有模式的粒子点大小。粒子点大小是固定随机个体属性。

## 检查点

新 `FlowParticleSystem.export_state()` / `from_state(...)` 包含位置、速度、朝向、寿命、活动状态、出生代数、半径因子、个体相位、色彩偏移、点大小、当前模式/参数、秒时间、RNG，以及带时间戳/代数的拖尾历史。

`VideoRenderer` 的 schema 1 快照增加可选 `flow`、`flow_seed` 元数据和 `flow_` 数组；旧快照仍可加载。恢复先验证并建立替代对象，再一次性替换。无 pickle。

## 验证与已知边界

新增测试涵盖纯上/下方向、fps 单位、环流半径/旋转方向、径向流、反向平滑过渡、三分量、全部模式有限性、种子一致性、2 秒尾迹、重生断尾、检查点和旧入口兼容。主任务统一执行，文件存在不代表测试已通过。

不同 fps 的积分路径与离散出生时刻不保证逐像素相同；速度单位和衰减时间保持按秒定义。相同 fps、种子、数值与检查点下，应以编码前像素验证一致性，而不是比较有损编码结果。环流中心允许位于画面边缘，因此部分轨道可以出画，但不会把离开画面的点通过取模传送到另一边。
