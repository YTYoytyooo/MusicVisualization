# 平滑过渡与即时编辑

## 操作流程

1. 刷新已打开的工作台，选择项目和修订。
2. 选择效价、唤醒度或视觉字段，设置时刻、目标值、前后过渡时间。
3. 在数值框输入或拖动已有情绪关键点，观察整段生效折线与黄色影响区域。无需先按预览按钮。
4. 离开输入框、按 Enter 或使用确认按钮，等待后台校验。这次连续输入只算一个撤销步骤；下一输入框是下一步。
5. 要放弃未确认调整，按 Esc 或点击取消；已确认的修改用撤销/重做。
6. 点击保存为新修订，再生成该已保存版本的视频。曲线变化不会改写旧视频。

无效的空值、越界、重叠影响范围不会进入正式草稿或撤销历史。输入错误时保留最后有效曲线；后台拒绝时恢复该输入会话最近一次被后台接受的曲线，并阻止保存，直到修正或取消。

## 四类状态

| 状态 | 是否改原始文件 | 是否进入撤销历史 | 刷新后是否保留 |
|---|---|---|---|
| 模型原始预测 | 始终只读 | 否 | 是 |
| 正在输入的即时调整 | 否 | 尚未进入 | 不保证 |
| 后台校验通过并确认的草稿 | 否 | 是，最多50步 | 浏览器本地存储可用时可恢复 |
| 已保存修订 | 否，另存新快照 | 当前草稿历史清空 | 是，保存在项目文件夹 |

输入框内 Ctrl/Cmd+Z 保留浏览器自己的文字撤销；离开输入框后 Ctrl/Cmd+Z 撤销草稿，Ctrl+Y 或 Ctrl/Cmd+Shift+Z 重做。新增修改清空重做分支。切换项目/修订会隔离历史与延迟响应。正在保存时会先等当前待确认操作完成，不能把未校验数据混入修订。

## 三种过渡如何选择

以一个过渡段的相对进度 u（0到1）表示影响权重：

| 模式 | 权重 | 用途 |
|---|---|---|
| linear | u | 匀速进入；兼容旧编辑 |
| smoothstep | 3u²−2u³ | 两端进入/退出速度归零 |
| smootherstep | 6u⁵−15u⁴+10u³ | 两端速度、加速度归零；新编辑默认 |

例如将第30秒唤醒度设为0.8、前后各2秒：28秒开始进入，30秒命中目标，32秒退出人工影响；28秒以前和32秒以后保留原始情绪数值。旧编辑缺少 interpolation 时仍是线性，不自动改变旧版视频含义。

这里平滑的是**人工影响权重**。原始预测按0.1秒采样保持，原曲线自身的跳变仍可能存在；这不是整曲平滑滤波。单点要求前后非零过渡，且影响范围不能超出歌曲；区间编辑可设零过渡，但零过渡本身意味着突变。

## 视觉参数与等待

视觉折线展示真实自动规划与人工修订值，而非示意曲线。第一次读取尚无缓存的规划会排队计算。准备好后，视觉值的输入也在本地立即画出。

纯视觉修改复用当前情绪对应的规划。若先改粒子速度等视觉字段，再改情绪：情绪折线先立即变化，后台为候选情绪准备对应真实规划，随后自动继续校验与确认。界面显示等待状态；无需人为删除视觉修改，也不会把旧规划误当成新基线。规划失败或取消时不能保存该未通过的调整，可修正重试或取消。

色相沿短弧变化；粒子数量和拖尾等整数参数最终取整，因此数值可能呈小台阶。情绪修改会影响自动规划和粒子历史，人工作用区间结束不意味着之后每个像素与原视频完全一致。

## 性能与一致性

本地绘图按画布像素列保留峰谷和人工关键点，仅减少画线顶点，不减少底层采样或越界校验。后台校验、真实规划、保存和视频生成都不是“即时本地绘图”耗时的一部分。

前后端使用相同过渡语义和已知答案用例；正式生成使用同一份参数写逐帧数值并渲染。偏移内部极值也会检查，不能只靠几个显示点判断安全。原始数据、已有修订和旧视频保持不变。

验收范围与实测结果见 [验收记录](VERIFICATION.md)。人工修订改善的是可控性与主观匹配，不等于证明模型识别准确率提高。
