# V2 / mixed / B01 固定对照

此目录提供独立加载、输入契约和运行前核验，不修改旧应用及已有模型。

V2 使用原代码的 22050 Hz 单声道解码、0.1 秒步长、向前 2 秒 CLAP 窗口和 10 帧历史滑窗。mixed/B01 使用各自训练时的 531 维缓存、0.5 秒居中窗口、训练归一化器与整曲双向推理。禁止用新模型缓存前 512 维冒充 V2 特征。

V2 处理器在全短窗口批次中随机设置一个 fusion 标志；对照保留这一行为、固定每曲种子 42 和特征批量 16。GPU 移植先与未经修改的 V2 CPU 提取和预测函数核验。结果只对应登记的独立环境，不宣称重现所有历史应用缓存。

`python -m tools.train_next_v2.cross_version.preflight --tests` 记录契约测试；`--prepare` 固定 584 首原验证集的身份、哈希、模型和评分口径，再登记核验任务。使用 launch.json 中的 argv/cwd/environment 执行。失败先核对实际进程、OS 锁和原因，再用原命令加 --resume；只接受完整哈希凭证。`--verify` 用新进程重新加载全部权重；`--status` 检查实际锁、进程身份及退出状态、有限日志和凭证。

预检使用三首已有无标签目标音频。V2 编码器核验采用第一首的前 3.23 秒，覆盖两个批次与补零边界；mixed/B01 使用三首完整时间轴。该步骤不是情绪精度评估。

后续正式对照在同一有效真值时刻评分，保留 V/A 独立掩码，不插值标签、不跨缺口计算变化率。共同排除 V2 未覆盖的末尾标注并报告数量。逐库逐维报告 CCC/MAE/RMSE、均值、振幅、动态残差、常量化对照、诊断时延及歌曲组配对 bootstrap。B01 分别计分，主比较取三个固定种子的指标均值；固定平均曲线是额外集成结果，不能选择最佳种子。

验证集曾参与 mixed 选模，V2 权重缺少完整训练来源。因此是存在已知局限的版本诊断，不是未见外部泛化测试。B01 未通过内部非劣门槛，本对照不能改写该结论或回流调参。622 首最终测试标签保持封存；不生成伪标签或切换应用。
