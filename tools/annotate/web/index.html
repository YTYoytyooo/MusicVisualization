怎样标才有用？

以整首歌为单位，边听边移动情绪点。记录的是音乐表达的情绪，不是个人喜好。

选择仅效价、仅唤醒或两者，再选择相应数值（把握程度可稍后补填），再开始记录；没有变化时保持坐标即可。不确定时勾选“不确定”，不以 0 代替。

明显转折单独打点，可以暂停后精确修改时间。暂停、跳转或切到后台会结束记录，继续时手动开始。

空格开始/暂停记录（输入文字时除外）。重标覆盖所选维度的重叠时间范围，其他维度和时间范围保留。旧版分段标注仍保留在原目录。
