# 音乐情绪人工标注（下一版数据）

双击根目录 `Start Annotation.cmd`，打开 http://127.0.0.1:8766 。保持终端窗口打开。
默认扫描项目内的 `assets/audio`。从 GitHub 下载的项目不包含音乐目录，首次启动会自动创建空目录；打开网页后即可拖入音乐。使用 `--audio-dir` 时，指定的外部目录须已存在，终端会显示实际读取路径。可以把音乐文件拖入左侧音乐库，或点击“拖入音乐”选择文件（支持多首）。文件只复制到本地 `assets/audio/imports`（自定义音频目录时为其 `imports` 子目录），不上传到外部服务；导入后立即出现在音乐库，无需重启。支持 MP3/WAV/FLAC/OGG/M4A/AAC，每首上限 512 MB；同名同内容的重复导入复用文件，不同内容不会覆盖。工具不加载预测、不训练、不覆盖现有模型。

## 按整首歌连续标注

1. 填写标注者代号，选择歌曲。建议先完整试听，熟悉情绪走向。
2. 在三选一按钮中选择仅效价 V、仅唤醒 A 或两者。只需选择本次维度的数值，把握程度可先留空，再点击开始或按空格。可以先完整标一遍效价，再从歌首单独标唤醒度。
3. 随着歌曲播放，按住二维情绪板拖动，或调整两个滑杆；没有变化时保持坐标。整首歌不会被固定切段。
4. 遇到明显转折，点击开始按钮后面的“明显转折”或按 M（输入框内不生效）。直接记录时间，无需选择类型。时间轴下方的转折时间标签可点击，弹窗内修改时间/备注或删除；不另设转折区域。旧数据中的类型仅保留为兼容元信息。
5. 不确定时勾选“不确定”，这一时刻起记录空值；不要用中性 0 代替不确定。
6. “开始标注”按钮点击后变为“暂停并保存”，再次点击即暂停保存，不另设暂停按钮。空格执行同样的开始/暂停操作；滑杆或按钮有焦点时也生效。文字输入框、下拉框、复选框中保留原生键盘操作。长按不会重复触发。跳转、变速、切到后台或播放结束也会停止记录并保存。播放器自身的播放按钮仅用于试听。
7. 重复标注覆盖所选维度在实际记录起止时间内的旧内容，区间外和未选维度保持不变。不确定空值也会覆盖旧值；未播放的区间不覆盖。转折点保持独立。历史修订仍可用于找回旧内容。展开曲线列表可删除不需要的有效曲线，再保存。
8. 标完后，展开“把握程度与完成状态”，选择维度、起止时间和把握程度，点击“应用并保存”。只修改已记录的明确数值的把握程度，不修改 V/A 或不确定空值；留空表示暂不评估。
9. 分别勾选“效价已完成”“唤醒已完成”，音乐库会显示两项状态；两项都确认后显示“已完成”。完成状态由人工确认，不把听完自动视为标完，也不要求先填把握程度。重标或删除某维度曲线后，该维度恢复为进行中。音乐库支持按完成状态筛选，状态按标注者独立保存。
10. 修改转折、歌曲备注后点击“保存进度”。需要备份时导出完整 JSON。

## 时间轴与复核回放

- 时间轴支持“放大 / 缩小 / 全曲”按钮；滚轮围绕指针位置缩放，拖动曲线区域平移。缩放最小范围为 1 秒（不足 1 秒的音频显示全曲）。点击曲线定位播放，缩放和平移不改动标注。
- “复核回放”与开始、转折按钮位于同一排，在现有二维板上显示已标注内容，不创建独立复核区域。再次点击暂停复核，空格也可暂停/继续。
- 复核读取原始时间采样，区间内使用最近一个已记录值；不跨越未标注区间或不确定空值补线，不写入采样或改动已保存的曲线。
- 只有一个维度有标注时，用方形点显示该维度，另一维度在文字中显示“此处未标注”；坐标缺失的一轴暂放在中心用于显示，不代表数值 0。两维都缺失时隐藏点。
- 复核时二维板与滑杆不接受标注输入。暂停复核后点击“开始标注”，恢复之前人工选择的坐标后开始记录，不会将回放坐标自动作为人工输入。

## 标注标准

标注音乐表达的情绪，而非个人喜好、画面效果或仅歌词含义。

- V：−1 负面/忧伤，0 中性，+1 正面/愉悦。
- A：−1 平静/低唤醒，0 中等，+1 激动/高唤醒。激烈不等于开心，音量不直接等于激烈程度。
- 把握程度（可选，可标完后调整）：高=判断清楚，中=大致确定，低=留待复核。不是模型概率。
- 转折：标变化发生或开始变化的时刻，不分类型；可在备注写“鼓点进入，由平静转为紧张”。

初始滑杆位置不算标签，必须主动选择本次维度；明确选择的 0 是有效中性值。
先选不同风格、不同情绪的歌曲，保持同一标注标准；疲劳时暂停。多人使用不同代号。

## 数据与时间

新数据：`data/annotations/continuous/<标注者>/<歌曲ID>.json`。
旧分段数据仍在原 `data/annotations` 下，工具不会迁移、转换或覆盖。
如自定义 `--output`，必须使用独立目录；检测到旧协议会拒绝写入。

以歌曲为一个文档，`takes` 保存覆盖处理后按维度分开的有效时间采样（`axes` 指明维度），`transitions` 保存独立转折。
目标采样间隔 250 毫秒，拖动时也记录变化，时间取自音频播放位置。
这是连续人工曲线的数字采样，不是固定时长分段或片段平均值。
不进行平滑、自动插值或人为反应延迟校正；暂停和跳转不会连接成完整曲线。
页面调度或播放中断超过 1 秒会停止本次记录；应保持页面在前台、正常倍速。
曲线空白可能是未记录或不确定；完整 JSON 保留空值及状态。

以最新标注优先，按维度覆盖闭区间 [本次首采样时间, 本次末采样时间]。旧曲线在覆盖区间两侧分别保留，不跨越覆盖范围连线，也不在边界插入推测值。每段有效曲线有 `take_id`；缺失维度不是中性值。CSV 的 `axis` 明确区分效价、唤醒度；两者的采样时间可以不同，后续需明确对齐规则。旧连续数据未提供 `axes` 时按两维读取；下一次保存时整理为有效曲线，历史修订保留保存前的数据。
同一歌曲未来必须归属同一训练/验证/测试分组；当前工具不分组、不训练。

有效 CSV：高/中把握的明确采样及转折行；未评估把握程度的采样暂不包含。全部 CSV 与完整 JSON：包含所有采样（含未评估）及转折行。未评估不等于低把握，完成状态也不等于高把握。
通过 `record_type=sample/transition` 区分；转折行没有 V/A，不是中性值。
完整 JSON 保留源音频 SHA256、歌曲元信息、原始记录和修订号，适合备份与后续处理。
CSV 的文本防公式转义，原始文字以 JSON 为准。

停止记录时保存到磁盘；记录期间每秒备份浏览器草稿，关闭前仍应停止并确认“已保存”。
重开时同一修订号与音频的草稿可恢复；版本不一致不会自动恢复。
历史修订在 `history` 子目录。不要修改正在标注的原音频；身份变化会阻止沿用标签。

## 启动与验证

```powershell
.\venv\Scripts\python.exe tools\annotate\server.py
# 自定义音频目录、独立输出目录、端口：
.\venv\Scripts\python.exe tools\annotate\server.py --audio-dir D:\Music --output D:\LabelsContinuous --port 8766
.\venv\Scripts\python.exe -m unittest discover -s tools/annotate/tests -p "test_*.py"
```

服务只监听本机，需要浏览器支持的音频格式；工具不改写源音频。
